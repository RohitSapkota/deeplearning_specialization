# Deep Learning Specialisation — Coursework

My completed programming assignments from the [DeepLearning.AI Deep Learning Specialisation](https://www.coursera.org/specializations/deep-learning) (Andrew Ng), finished in October 2025. Everything from building neural networks from scratch in NumPy to Transformers in TensorFlow.

> These are course assignments, shared as a record of my learning. If you're taking the course, please do the work yourself first.

## What's inside

| Course | Highlights |
|---|---|
| [Neural Networks and Deep Learning](./NeuralNetworks_and_DeepLearning) | Logistic regression as a neural net, a planar classifier with one hidden layer, a deep neural network built step by step |
| [Improving Deep Neural Networks](./Improving%20Deep%20Neural%20Networks%3A%20Hyperparameter%20Tuning%2C%20Regularization%20and%20Optimization) | Initialisation, regularisation, gradient checking, optimisation methods (momentum, Adam), intro to TensorFlow |
| [Convolutional Neural Networks](./Convolutional%20Neural%20Networks) | CNNs from scratch, ResNets, transfer learning with MobileNet, YOLO car detection, U-Net image segmentation, face recognition, neural style transfer |
| [Sequence Models](./Sequencial%20Models) | RNNs and LSTMs from scratch, character-level language model, jazz generation, word vectors, neural machine translation with attention, trigger-word detection, Transformers, named-entity recognition and question answering |

Also included: `Lab_3_fine_tune_model_to_detoxify_summaries.ipynb` — fine-tuning a language model to produce less toxic summaries, from the *Generative AI with Large Language Models* course (DeepLearning.AI + AWS).
